# Atannex Retrive

A single place for a Laravel app to fetch its records. For each model you describe once what can be filtered, sorted and included and who may see what, and then fetch records with simple calls such as getPostBySlug or getPostsByCategory. It handles filters from the web address, search, next and previous records, related records and caching that clears itself when data changes.

## Install

```bash
composer require atannex/retrive
```
